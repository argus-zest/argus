# AI Tools Used

1. **Google Antigravity**: AI-assisted software engineering and codebase management pair-programmer used throughout project scoping, implementation, debugging, and testing.
2. **Amazon Bedrock (Amazon Nova 2 Lite)**: Used for vision-based hazard detection, verification of repair claims, and extraction of defect-liability contract clauses (`global.amazon.nova-2-lite-v1:0` / `amazon.nova-2-lite-v1:0`).
3. **Claude**: Used for architectural brainstorming, technical reasoning, code review, debugging, and refining implementation approaches.
4. **Codex**: Used for AI-assisted coding, implementation support, debugging, and code-level problem solving.
5. **OpenCode**: Used as an AI-assisted development environment for code generation, debugging, and iterative software development.
6. **Impeccable**: Used for reviewing and refining the user interface, removing generic AI-generated design patterns ("AI slop"), and improving visual consistency and usability.
7. **Claude Code**: Used for agentic software development, repository-level code modifications, debugging, testing, and implementation of project features.
8. **Remotion**: Used to create and render the Argus demonstration video programmatically.
9. **ChatGPT**: Used for demo-video ideation, narrative structuring, concept development, and refining the presentation of Argus.
10. **Agent Toolkit for AWS**: Used for developing, testing, and integrating agentic workflows within the AWS environment.
11. **Kokoro**: Used for generating the voiceover narration for the Argus demonstration video.
